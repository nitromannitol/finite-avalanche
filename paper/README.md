# Manuscript

Ahmed Bou-Rabee, *Sandpile avalanches in two dimensions are finite*.

The manuscript sources, bibliography, seven figure PDFs and existing compiled PDF are copied unchanged from author revision `d2fc033fa59b56deff4c7b543387bdcbabfec82d`. The compiled PDF has not been rebuilt as part of this release. Downloaded third-party literature is not included. Software and manuscript licensing remain unspecified; the separate Mathlib source notices apply only to those source mirrors.

With pdfLaTeX, BibTeX and latexmk installed, run `make` in this directory to rebuild the PDF.
